# Diabète de type 2

## Définition

Le diabète de type 2 est une hyperglycémie chronique liée à une insulinorésistance associée à un déficit relatif de l'insulinosécrétion.

## Critères diagnostiques

| Critère | Seuil |
|---|---|
| Glycémie à jeun | ≥ 1,26 g/L (2 fois) |
| Glycémie aléatoire + symptômes | ≥ 2 g/L |
| HbA1c | ≥ 6,5 % |

## Complications

- Microangiopathiques : rétinopathie, néphropathie, neuropathie
- Macroangiopathiques : coronaropathie, AVC, artériopathie des membres inférieurs

> Le dépistage annuel des complications est indispensable dès le diagnostic.

## Traitement de première ligne

La **metformine** reste le traitement de première intention en l'absence de contre-indication.
